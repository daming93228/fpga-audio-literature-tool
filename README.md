# FPGA Audio Literature Tool

A personal research tool for literature discovery in **FPGA-based digital
audio processing**.

## Overview

This repository documents a small, personal research utility used to
discover and organize technical literature for FPGA audio DSP development
(e.g., digital mixing consoles, fixed-point DSP pipelines, real-time audio
effects).

The tool helps with:

- **Searching** technical literature metadata (IEEE Xplore, arXiv) for
  FPGA and audio-DSP topics
- **Retrieving open-access full text** to build a personal reading list
- **Organizing** a local, searchable archive of reading materials

## Scope & Compliance

- Personal, non-commercial research use by a single researcher
- Low-volume, human-driven queries — well within free API tier limits
- **Open-access content only** (e.g., IEEE Xplore Open Access API); no
  paywalled content is accessed
- Downloaded materials are for personal reading only and are **not
  redistributed**

## Topics of Interest

FPGA implementations of: digital filters (FIR/IIR), beamforming, audio
codecs, dynamic-range processing, spatial audio, and real-time DSP
pipelines for professional audio.
